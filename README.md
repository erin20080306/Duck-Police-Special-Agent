# 鴨警特工 · Duck Force

以 Three.js 製作的第一人稱單人戰術射擊遊戲。場景參考使用者提供的 Astral War 錄影，朝灰暗工業廢墟、鋼架屋頂、濕地與煙雨的氣氛調整；主角保留奶油色絨毛鴨頭、深海軍藍警用長外套與黑色大盤帽，搭配白襯衫、黑領帶、金色徽章及鍊飾、青藍發光模組，敵人改為三種喪屍。

角色與建築是程式化幾何搭配材質的風格化近似，並非參考影片或人物圖片的精確重建。目前沒有匯入 Blender 雕刻模型、動作捕捉或真人多人連線。

## 場景與戰鬥

- **鋼鐵廢墟**：破損弧形鋼架棚頂、分層工業天際線、吊車、水塔、屋頂通風設備、管線、碎裂女兒牆與隔離標示。保留貨櫃、裝甲運輸車、沙包及路障形成的通行路線。
- **雨夜神社**：鳥居、瓦頂、石燈籠、庭院與枯樹，加入地面薄霧、雨線、燈暈與濕地光影。
- **戰場效果**：陰雲天空、煙囪與排氣口蒸汽、細雨、積水與流動光紋；射擊包含槍口火光、煙霧、彈殼、命中塵屑與死亡效果。環境與戰鬥粒子數量都有上限。
- **三種喪屍**：感染工人靠近後近戰；狂奔喪屍快速追擊；狙擊喪屍以紅色瞄準線預警後射擊。AI 依掩體判斷視線並尋路，玩家可用蹲姿躲在低掩體後。
- **武器與任務**：AR-07 突擊步槍、P-09 戰術手槍，支援瞄準、後座力、換彈與切槍。三種難度、三波清剿、行動倒數、有限彈藥、波次補給、命中判定與結算。

特工技能為**脈衝護盾**：按 Q 或手機技能鍵，對 10 個場景單位內且未被掩體阻擋的喪屍造成 55 傷害並暈眩 2.4 秒，同時獲得 4 秒護盾，減少 75% 傷害；冷卻 18 秒。技能狀態與冷卻顯示於 HUD。

## 電腦與手機操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD | 左側上滑前進、下滑後退，放手即停 |
| 轉向 | 滑鼠；無法鎖定游標時拖曳 | 左側左右滑轉向，或右側滑動微調 |
| 開火 | 左鍵；手槍每次點擊 | 預設準星對準喪屍自動開火，亦可用開火鍵 |
| 瞄準 | 按住右鍵 | 瞄準鍵切換 |
| 技能 | Q | 脈衝技能鍵 |
| 換彈 | R | 換彈鍵 |
| 切槍 | 1 / 2 | 切槍鍵 |
| 蹲下 | C | 蹲下鍵 |
| 快速前進 | Shift + WASD | 搖桿往前推即快跑 |
| 暫停 | Esc / P | 右上暫停鍵 |

直向與橫向皆有手機配置，橫向可獲得較寬視野。開始時保留使用者的直向／橫向選擇；全螢幕由部署頁按鈕手動啟用。手機預設「輔助射擊」：準星對到沒有掩體遮擋的喪屍時自動開火，可在設定切換為手動射擊。搖桿前推即快跑，瞄準或蹲下時減速，無需另一顆疾跑鍵。左側預設是浮動單指控制：可從任意空白處上滑前進、下滑後退、左右轉向，斜上滑可邊轉邊跑；設定可切換為左右平移。視角使用依時間平滑的跟隨並依螢幕短邊統一靈敏度。左側、右側視角區與操作按鍵分別追蹤觸控指標，支援同時移動、轉向與射擊。切換分頁、失焦或取消觸控時會清除輸入，避免持續移動或開火。

手機自動使用效能配置：降低像素比與環境粒子量、限制局部燈光，關閉動態陰影及桌面後製；手機不建立 PMREM 環境反射。畫面解析度可隨持續的幀時間壓力降低。靜態環境和角色按材質合併幾何，以控制繪製次數；這些限制仍需要真實裝置量測確認效果。

## 安裝到主畫面與離線遊玩

正式版包含 Web App Manifest、應用程式圖示與 Service Worker。首次請保持連線，等待大廳顯示「離線戰區已備妥」；程式會預先快取該次正式建置的頁面、JavaScript、CSS、材質與圖示，之後可離線載入兩個戰區。瀏覽器清除網站資料或回收快取後，需要重新連線準備。

- **Android／支援安裝提示的桌面瀏覽器**：在大廳按「安裝到主畫面」，依提示安裝；若尚未提供原生提示，可依畫面說明從瀏覽器選單操作。
- **iPhone／iPad**：使用 Safari 開啟網站，按「分享」→「加入主畫面」→「新增」。若系統顯示「以網頁 App 開啟」，請保持開啟。安裝後從主畫面圖示啟動。[Apple 操作說明](https://support.apple.com/en-ae/guide/iphone/iphea86e5236/ios)
- **更新**：新版本完成快取後，大廳會顯示「套用遊戲更新」。按下後才重新載入；遊戲進行中不主動重新整理。

正式部署需使用 HTTPS；本機 `localhost` 或 `127.0.0.1` 可用於開發測試。安裝入口、全螢幕與主畫面啟動方式由瀏覽器／作業系統支援情況決定。[MDN：PWA 安裝條件](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

`npm run dev` 不註冊 Service Worker，以免快取干擾開發。請用下方的正式建置預覽驗證安裝與離線功能。

## 本機開發

需要 Node.js 22.12 以上：

```sh
npm ci
npm run dev
```

執行自動測試及正式建置：

```sh
npm test
npm run build
npm run preview
```

預覽網址以 Vite 終端輸出為準。PWA 應在 `npm run preview` 的正式建置中驗證；手機若透過區域網路 IP 測試，仍需為安裝與 Service Worker 提供安全來源。

## Vercel

匯入 `erin20080306/Duck-Police-Special-Agent`，Root Directory 保持根目錄，Framework 選 **Vite**。

- Install：`npm ci`
- Build：`npm run build`
- Output：`dist`

不需要環境變數、API Key 或資料庫。若 Vercel 已連接此 repo 的 main，GitHub 更新是否自動部署取決於該專案的設定。

## 驗證範圍

自動測試涵蓋視線與掩體、移動防穿牆、彈藥守恆、尋路、兩張地圖的出生點與路線、喪屍幾何及動畫節點、脈衝範圍／掩體阻擋、護盾減傷、環境資源釋放與手機場景預算。PWA 測試涵蓋完整建置快取、離線導覽、更新版本保留、快取作用域、圖示尺寸及安裝提示流程。

本輪已在 Chromium 瀏覽器檢查桌面及 390×844、844×390、568×320 手機版面，驗證單點射擊、準星輔助射擊、轉向、單指移動、技能及暫停。停止正式版伺服器後重新載入並切換神社／使用技能成功，驗證遊戲本體可從 Service Worker 快取離線啟動。**尚未完成真實 iPhone／Android 裝置的觸控、安裝、離線與持續效能驗證，不宣稱手機穩定 60 FPS。** Node 測試中的 DOM／Service Worker 模擬不代表作業系統已實際安裝成功。

發佈前的瀏覽器與實機確認項目：

1. 兩個戰區可開始、暫停、繼續、返回大廳；三種喪屍可正常攻擊，狙擊預警、掩體與技能冷卻符合畫面提示。
2. 直向及橫向介面不遮住主要按鍵；同時移動、滑動轉向、開火和施放技能，放開或中斷觸控後輸入確實停止。
3. 正式版等待離線備妥後切斷網路，再重新開啟並切換兩個戰區；確認材質、武器、音效與 UI 均可用。
4. 安裝到 Android／iOS 主畫面後重新啟動；檢查安全邊界、旋轉、背景切換、更新提示及長時間遊玩的溫度與幀時間。

## 素材與技術

Three.js 採 MIT 授權。音效由 Web Audio 在本機合成，字型使用裝置可用字型與系統備援；遊戲不依賴外部字型下載。

混凝土材質 `public/assets/concrete.webp` 使用內建 imagegen 生成並儲存為 WebP。原始提示詞：photorealistic worn gray industrial concrete surface texture; flat orthographic material scan; fine grain, hairline cracks, damp stains, chipped flecks; neutral gray, flat diffuse lighting, no objects/text/logos. 提示要求可平鋪，邊界連續性未作像素級驗證。

### 擴大戰區

兩張地圖的可行走邊界由 40 × 72 擴大至 64 × 120 個場景單位（約 2.67 倍範圍），保留主街，新增相通的北側貨運／勤務庭院、南側撤離／石庭、西側維修巷與東側巡邏巷。新增六個喪屍出生點，波次會輪替使用外圍區域；HUD 顯示所在分區。
